# 🎮 GamePicker

Локальное приложение, которое смотрит, во что ты играешь больше всего в Steam, и подбирает **несколько** игр, которые могут зайти — включая малоизвестное инди.

Для тех, кто любит пробовать новое и долго не может выбрать, что купить.

## Что умеет

- **Подбор по библиотеке** — берёт ~20 игр, в которые ты наиграл больше всего (недавние весят сильнее), строит профиль твоих любимых тегов и ищет похожие игры, которых у тебя ещё нет.
- **Подбор по категориям** — выбираешь один или несколько тегов (рогалик, выживание, уютные…), можно требовать «все сразу» или «любой». Теги можно и **исключать** (второй клик по тегу).
- **Несколько разных игр, а не один хит** — алгоритм специально разнообразит выдачу, чтобы не было 12 клонов одной игры. Кнопка «Ещё варианты» даёт следующую порцию.
- **«Почему тебе»** — под каждой игрой: на какую твою игру она похожа, сколько ты в неё наиграл и какие теги общие.
- **Что говорят игроки** — сводка по 100 самым полезным отзывам Steam: что хвалят, что ругают (сюжет, оптимизация, баги, гринд, донат…), сколько обычно наигрывают, плюс самый полезный «за» и «против».
  С ключом Anthropic API — ещё и короткий пересказ от Claude: кому зайдёт, кому нет.
- **Скриншоты и трейлеры** — превью на каждой карточке и просмотр на весь экран; трейлеры Steam (HLS) играют прямо в приложении.
- **TikTok** — кнопка на карточке открывает вертикальное окно с поиском видео об игре в TikTok (вход в аккаунт запоминается).
- **Фильтры**: максимальная цена (в валюте твоего региона), только со скидкой, только бесплатные, минимальный % положительных отзывов, минимум отзывов.
- **Режим «скрытые жемчужины»** — малоизвестные игры с хорошими оценками вместо популярных хитов.
- **«Не интересно» и «Уже есть»** — скрывают игру из подбора навсегда. Все скрытые игры видны на вкладке «Скрытые», оттуда их можно вернуть.
- **Семейная библиотека Steam** — ключ Steam API не видит игры семьи, поэтому их можно один раз импортировать в Настройках, и они перестанут попадать в подбор.
- **Язык интерфейса**: русский, украинский, английский. Описания игр и отзывы тоже подтягиваются на выбранном языке.

## Запуск

Нужен только **Python 3.9+** (сторонние библиотеки не нужны).

1. Получи бесплатный ключ Steam Web API: <https://steamcommunity.com/dev/apikey> (в поле «домен» можно написать `localhost`).
2. В Steam открой: Профиль → Редактировать → **Приватность** → «Сведения об играх» → **Открытые**.
3. Запусти:
   - Windows: двойной клик по `run.bat`
   - macOS / Linux: `./run.sh` (или `python3 app.py`)
4. Откроется <http://127.0.0.1:8765>. В настройках укажи ключ и ссылку на профиль.

Первый подбор занимает 1–2 минуты (SteamSpy разрешает 1 запрос в секунду), дальше всё берётся из кэша и работает быстро.

Ключи хранятся только у тебя в `config.json` (он в `.gitignore` и не попадает в репозиторий). Можно задать их и через переменные окружения `STEAM_API_KEY` и `ANTHROPIC_API_KEY`.

## Как устроено

```
app.py          — локальный веб-сервер и фоновые задачи с прогрессом
steam_api.py    — Steam Web API, магазин Steam, SteamSpy; кэш и ограничение частоты
recommender.py  — профиль вкусов и алгоритм подбора
summarizer.py   — анализ отзывов (локальный + опционально Claude)
userdata.py     — скрытые игры и семейная библиотека (userdata.json)
static/         — интерфейс (HTML/CSS/JS, переводы в i18n.js)
```

**Источники данных**
- `IPlayerService/GetOwnedGames` — твоя библиотека и наигранные часы
- SteamSpy — пользовательские теги игр, число отзывов и владельцев, списки игр по тегу
- `store.steampowered.com/api/appdetails` — цена в твоём регионе, описание, обложка
- `store.steampowered.com/appreviews` — отзывы

**Алгоритм**
1. Профиль вкусов: теги топ-игр, взвешенные по `log(часы)` + бонус за последние 2 недели. Слишком общие теги («Инди», «Экшен», «Для одного игрока») получают меньший вес.
2. Кандидаты: все игры с твоими 6 главными тегами (или с выбранными категориями), без тех, что уже есть в библиотеке.
3. Быстрая оценка: совпадение тегов + качество (нижняя граница Уилсона по отзывам, чтобы 100% из 5 отзывов не обгоняло 95% из 50 000).
4. Для лучших ~30–40 загружаются полные теги и цены; итоговая оценка = косинусная близость к профилю + качество + популярность (или «незаметность» в режиме жемчужин).
5. Разнообразие выдачи (MMR): каждая следующая игра штрафуется за похожесть на уже выбранные.
